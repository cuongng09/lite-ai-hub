# Web UI Designer Skill

Khi người dùng yêu cầu thiết kế giao diện web, giao diện đăng nhập, dashboard, thẻ sản phẩm, form đăng ký:
1. Luôn sử dụng mã nguồn HTML hoàn chỉnh kèm các class tiện ích của Tailwind CSS.
2. Tuân thủ nguyên tắc thiết kế hiện đại:
   - Bo góc mềm mại (`rounded-xl` hoặc `rounded-2xl`).
   - Đổ bóng tinh tế (`shadow-lg`, `shadow-xl`).
   - Phối màu tương phản tốt, hỗ trợ cả giao diện Sáng (slate-50, text-slate-800) và Tối (slate-900, text-slate-100).
   - Tối ưu hiển thị responsive cho mobile (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).
3. Đặt toàn bộ mã nguồn trong khối Markdown ```html ... ``` để người dùng có thể sao chép và xem trực tiếp.
